1. 서비스 기본 정보

서비스명 대전서구 청년공간 '청춘스럽' AI 정책 안내 챗봇 (Youth Policy Bot)
서비스 형태 웹 기반 대화형 AI 시스템 (Web App / Mobile Responsive)
신청 API 목록 1. 한국고용정보원 온통청년 청년정책 API
2. 고용24 통합 일자리 지원 정보 API
주요 서비스 대상 대전광역시 및 전국 청년(18세~39세), 대학생, 구직자, 청년 가구

2. 서비스 개요 및 목적

  • 개발 배경: 수많은 정부 및 지자체 청년 지원 사업(일자리, 주거, 금융, 복지 등)이 복잡하게 흩어져 있어 청년들이 본인에게 맞는 혜택을 제때 신청하지 못하는 문제 해소.
  • 서비스 목적: 청년들이 일상 언어(자연어)로 질문하면 GPT-4o 기반 AI가 공공 API에서 최신 데이터를 실시간으로 조회하여 자격 조건, 혜택, 신청 링크를 한눈에 맞춤 안내.
  • 청춘스럽 공간 연계: 대전 서구 청년공간 '청춘스럽' 이용 청년들에게 오프라인 공간 및 온라인 정책을 통합 안내하는 원스톱 청년 지원 플랫폼 구축.

4. 주요 서비스 기능

  1. AI 대화형 정책 추천: "대전 월세 지원받으려면 어떻게 해?"와 같이 편한 질문 시 맞춤 정책 추출 및 답변.
  2. 맞춤형 필터링: 분야별(일자리·주거·금융·복지·교육) 및 지역별(대전 5개 구 / 전국) 맞춤 정책 칩 제공.
  3. 공식 신청 원클릭 이동: 답변 하단 카드 및 텍스트 내 링크를 통해 대전청년포털/고용24로 바로 접속.
  4. 보안 및 가독성: 개인정보 수집 최소화 및 다크/라이트 브랜딩 테마 기반 초보자 친화 UI.

5. 데이터 관리 및 보안 계획

  • 개인정보 보호: 회원가입 없이 익명으로 이용 가능하며, 개인정보나 주민등록번호 등 민감정보는 저장하거나 API로 전송하지 않음.
  • 트래픽 및 트래킹 유의: API 호출 시 캐싱(Caching) 기술을 적용하여 서버 부하를 최소화하고 안정적인 서비스 유지.
  • 공공데이터 지침 준수: 출처 표기 및 공공데이터 개방·활용 가이드라인을 엄격히 준수.

본 설계서는 공공데이터포털 / 온통청년 OPEN API 활용 신청을 위하여 작성된 문서입니다.
